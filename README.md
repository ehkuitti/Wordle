A Java-based implementation of Worldle, a word-guessing game inspired by Wordle.
The objective is to guess a hidden word within a limited number of attempts using feedback provided after each guess.

This project was developed as part of a school assignment to practice Java programming and basic game logic.

🧠 Game Rules

The game selects a random word from a predefined list.

The player guesses the word by entering text input.

After each guess, feedback is given for each letter:

✅ Correct letter in the correct position

🟨 Correct letter in the wrong position

⬛ Letter not in the word

The player wins by guessing the word within the allowed number of attempts.
